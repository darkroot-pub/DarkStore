DarkStore API

Show every app published on DarkStore in your own store, website or app. You get JSON with names, icons, screenshots, versions, ratings and (if allowed for your key) the APK download link. Apps appear here only after they passed DarkStore's review, and the list updates by itself.

Statuschecking…

1. Get a key

Ask the DarkStore team for an API key (see our GitHub). Every key has its own speed limit and can be paused at any time. Keep it secret: call the API from your server, not from public JavaScript.

2. Make a request

Base address:

https://mjhuwxmpbxmqgtfkqvsc.supabase.co/functions/v1/store-api/v1

Send the key in the X-API-Key header (or Authorization: Bearer <key>). Only GET is supported.

curl -H "X-API-Key: YOUR_KEY" \
  "https://mjhuwxmpbxmqgtfkqvsc.supabase.co/functions/v1/store-api/v1/apps?limit=20&sort=rating"

Endpoints

EndpointWhat it returns
GET /appsA page of published apps.
GET /apps/{packageName}One app, e.g. /apps/com.example.app.
GET /categoriesCategories with the number of apps in each.
GET /statusWhether the API is on. No key needed.

Parameters for /apps

NameMeaning
qSearch words (name, package, developer, description). Needs the "search" permission on your key.
categoryOnly this category.
sortupdated (default), rating, name or new.
limitApps per page (default 20, usually up to 100).
offsetHow many apps to skip (for the next page).
updated_sinceISO date. Only apps changed since then, so you can sync cheaply, e.g. 2026-01-31T00:00:00Z.

download is only present if DarkStore allows it for your key and for that app. Some fields (description, screenshots, video, changelog) can be switched off by DarkStore.

Limits and errors

Every answer carries X-RateLimit-Limit and X-RateLimit-Remaining (per minute). When you go over, you get 429 with a Retry-After header. Cache the list on your side and use updated_since.

Statuserror.codeMeaning
400bad_requestA parameter is wrong.
401key_required / invalid_keyNo key, or the key is wrong, paused or expired.
403scope / ip_not_allowed / origin_not_allowedYour key may not do this, or not from here.
404not_foundNo published app with that package name.
429rate_limitedToo many requests. Wait and retry.
503api_disabled / unavailableThe API is switched off or busy. Try again later.

More examples

# JavaScript (Node 18+)
const r = await fetch(BASE + "/apps?limit=50", { headers: { "X-API-Key": process.env.DARKSTORE_KEY } });
const { data, meta } = await r.json();

# Python
import os, requests
r = requests.get(BASE + "/apps", params={"limit": 50}, headers={"X-API-Key": os.environ["DARKSTORE_KEY"]})
apps = r.json()["data"]

Please

  • Link back to the app's DarkStore page or say the apps come from DarkStore.
  • Do not re-host APK files; use the download.url we give you.
  • Remove apps from your store when they disappear from the API (they were unpublished or suspended).
