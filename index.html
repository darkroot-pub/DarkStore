How an app gets in

Nothing is published automatically.

  1. A developer submits it

    They send the app with its screenshots and details. While it waits, they can't queue another update for the same app.

  2. An admin reviews it

    The admin approves it, or rejects it with a reason. Updates go through the same check.

  3. It goes live

    Only approved apps appear in the catalog, so what you see has been looked at.

Install in three steps

DarkRoot Store isn't on Google Play, so you install the APK file yourself.

  1. Download the APK

    Use the download button on this page. Your browser may ask you to confirm the download.

  2. Allow the install

    When Android asks, allow installs from your browser or your Files app.

  3. Open it and tap Install

    Open the downloaded file and tap Install. Then sign in or browse as a guest.

Android shows a warning for any app installed outside Google Play. That is normal for APK files.

Questions

Is it safe to install?

Every app and every update is checked by an admin before it is published. Android still shows its standard warning for apps installed outside Google Play, because the file does not come from there.

Why isn't it on Google Play?

DarkRoot Store is distributed as an APK so apps can be reviewed and published by its own admins. You install it once and it updates itself from inside the app.

How do I update it?

The app tells you when a new version is ready and installs it from inside the app. You can also come back to this page and download the latest APK.

I can't install the APK.

Open Android Settings, search for "Install unknown apps", and allow your browser or Files app. Then open the downloaded file again.

I want to publish my own app.

Create an account in the app and use the developer option in Profile. Your app goes to the review queue, and an admin approves it or tells you what to change.
