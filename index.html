DarkRoot Store How to install

Install Android apps that were reviewed first.

DarkRoot Store is an app marketplace where an admin checks every new app and every update before it reaches your phone.

Download for Android

Android APK. The button opens Google Drive: tap the download icon there.

How an app reaches the store

Nothing is published automatically.

  1. A developer submits it

    They send the app with its screenshots and details. While it waits, they can't queue another update for the same app.

  2. An admin reviews it

    The admin approves it or rejects it with a reason. Updates go through the same check.

  3. It goes live

    Only approved apps show up in the catalog, so what you see has been looked at.

What you get

Reviewed apps and updates
One review at a time per app, so updates can't be flooded in.
Chat with developers
Message a developer directly, or join the global chat. Admins carry a blue tick.
Ratings and reviews
See what other people think before you install.
Report a problem
Found a bug or something unsafe? Send it to the admin from Settings.
Light, dark and themes
Pick the look you like, including Premium accent themes.
Your account stays protected
Sign-in tokens are encrypted on your device and cleared when you log out.

Install in three steps

DarkRoot Store isn't on Google Play, so you install the APK file yourself.

  1. Download the APK from the button above.
  2. When Android asks, allow installs from your browser or Files app.
  3. Open the downloaded file and tap Install.

Android shows a warning for any app installed outside Google Play. That is normal for APK files.
